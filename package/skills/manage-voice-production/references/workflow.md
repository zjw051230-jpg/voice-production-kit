# 多项目配音目录与流程

## 工作区

工作区根目录放 `项目注册表.json` 和各独立项目：`工作区\项目1`、`工作区\项目2`。不同项目不得共用角色素材、任务 JSON 或输出目录。

## 项目真实目录

```text
项目1\
├─ 01_输入资料\
│  ├─ 01_角色音色参考\
│  ├─ 02_剧情与剧本\
│  ├─ 03_配音任务\
│  └─ 04_临时素材\
├─ 02_生产成品\
│  ├─ 01_生成视频\
│  └─ 02_MP3音频\
├─ 03_交付与版本\
│  ├─ 01_待提交资料\
│  ├─ 02_工作版本\
│  └─ 03_历史版本\
└─ 04_管理与记录\
   ├─ 01_API配置\
   ├─ 02_操作日志与索引\
   ├─ 03_问题与改进\
   └─ 04_回收归档\
```

## Codex 隐藏管理目录

`.codex` 只存结构化元数据，不存媒体和密钥：

```text
.codex\
├─ 01_素材状态与选用.json
├─ 02_台词ID位置索引.json
└─ 任务清单\
   ├─ <task_ID_1>\
   │  ├─ 资料索引.json
   │  └─ 改动记录.md
   └─ <task_ID_2>\
      ├─ 资料索引.json
      └─ 改动记录.md
```

任何任务 JSON 新建或修改后，先运行 `sync_task_manifest.py`。素材缺失或多版本未选定时，只记录状态，不提交该角色生成。

## 标准流程

1. 音色放入 `01_输入资料\01_角色音色参考\<剧本>\<角色>`。
2. 六字段任务 JSON 放入 `01_输入资料\03_配音任务`。
3. 同步 `.codex`，确认每个角色素材已选中。
4. Seedance 默认 480p、9:16、未指定时 4 秒，每句四份并行生成。
5. 视频进入 `02_生产成品\01_生成视频`，完整音轨 MP3 进入 `02_生产成品\02_MP3音频`。
6. 返工记录追加到项目问题日志，同时追加对应台词的 `.codex` 改动记录。
7. 覆盖或删除前归档到 `04_管理与记录\04_回收归档`，同步维护日志和地址索引。

`sdc` 表示 Seedance 视频生成后提取 MP3；“拿到 ID 停”表示只提交并保存 ID；“拉回”表示只查询、下载和提取，不重新提交。
