# 新用户建项目问询

## 第一轮：先创建骨架

一次只问以下两个必填项：

1. 工作区放在哪里？若用户没有偏好，建议本机数据盘中的 `配音工作区`，不要默认网络共享路径。
2. 项目叫什么名字？说明工作区内项目名必须唯一。

收到答案后创建项目，向用户报告项目根目录，但继续第二轮，不要把空项目当作完成。

## 第二轮：建立可执行资料

用清楚的日常语言询问：

1. 这是什么剧本或系列？可以有一个或多个剧本名。
2. 台词从哪里来？让用户提供现有 JSON、剧本文件、表格或直接粘贴；没有时记录为待提供。
3. 有哪些角色？逐个确认角色名。
4. 每个角色有没有参考音频或视频？有则询问本机路径；没有则在素材状态中记为 `缺失`。
5. 同一角色有多版素材时，要用户明确选哪一版；没有决定就记为 `已有待选择`，不得擅自生成。
6. Seedance API 要使用 test版还是正式版？CC Switch 中是否已配置一份或多份对应 provider？只确认线路和就绪状态，运行自动导入程序，不询问或复述密钥。
7. 是否使用默认生成值：480p、9:16、未指定 4 秒、每句 4 份并行？只记录用户明确修改的项目。
8. 成品在本机交付到哪里？网络共享或服务器路径必须另外取得明确批准。

## 记录规则

- 角色素材状态和选择写入 `.codex\01_素材状态与选用.json`。
- 有任务 JSON 后运行 `sync_task_manifest.py`，自动生成台词位置索引和逐句任务清单。
- 信息不确定时写 `待确认` 或 `缺失`，不要填猜测值。
- 缺少台词或角色素材不阻止项目骨架创建，但阻止对应任务实际提交。
