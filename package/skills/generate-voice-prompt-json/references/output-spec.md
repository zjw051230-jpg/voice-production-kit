# 输出与提示词规范

## JSON 结构

根节点必须是数组。每个任务严格使用以下六个字段，字段顺序保持一致：

```json
[
  {
    "剧本名字": "诡雾·寻女",
    "task_ID": "ABC123_1",
    "角色名字": "月儿",
    "台词": "不到十分钟。",
    "时长": "4秒",
    "提示词": "……"
  }
]
```

- `剧本名字`：使用当前项目 `角色音色素材` 兼容路径下的一级分类目录名。它用于定位 `角色音色素材\<剧本名字>\<角色名字>`，必须与目录完全一致，同一文件内保持一致。
- `task_ID`：使用 `<task_id>_<x>`，x 是该对象在 JSON 数组中的序号，从 1 开始且不补零，例如 `ABC123_1`、`ABC123_2`。
- `角色名字`：使用剧本显示名或明确要求的配音版本名，如“玩家男声”。
- `台词`：逐字保留原台词和标点，不包含外层引号。
- `时长`：使用正整数秒字符串，如 `"4秒"`。
- `提示词`：写成单段中文，可直接独立复制给 Seedance 使用。

## 时长估算

1. 以普通话自然对话每秒约 3 至 4 个汉字为基线。
2. 计入标点停顿、情绪性停顿，以及台词前后合计约 1 秒安静。
3. 哭腔、虚弱、迟疑、庄重或长停顿要增加时长；急促指令可适度缩短。
4. 向上取整到整数秒，通常不低于 3 秒。时长应留有自然表演空间，不追求塞满。

## 提示词组成

按自然语言连成一段，依次覆盖：

1. **音色锁定（最高优先级）**：以用户上传参考音视频中的主要说话者为唯一音色基准，严格复刻参考素材本身的原始声音、音色与自然说话习惯；参考素材决定声纹、年龄感、地域特征、口音、音高、共鸣、声线厚薄、咬字和自然停连。不得用提示词重新指定、修饰或改造这些声音属性，也不得把角色背景中的年龄、籍贯或外形特征转成声音要求。提示词只控制本句的情绪、目的、语速、停顿、重音和收句。参考素材绝不提供“说什么”的文本内容；不得继承参考素材中的原台词、口头禅、旁白、第二人声或背景声音。
2. **场景与关系**：用一句话交代场景、角色身份、说话对象和此刻发生的事件，只写理解表演所需的信息。
3. **心理锚点与表演意图**：写清角色此刻知道什么、担心什么或想达成什么、对谁说，以及情绪是要压住还是泄露。再用主情绪、次情绪、真实目的和克制边界落到声音上。例如“表面平静地通报，实际害怕对方先崩溃，所以把焦急压在语尾”，不要堆砌相互冲突的形容词。
4. **精确台词白名单**：把原台词声明为“成片唯一允许发声的内容”，要求完整说一次、字词与顺序完全一致。明确禁止在前后或中间添加开场白、称呼、回应、解释、语气词、口头禅、旁白、重复、改写、漏词、续写或第二句话；冲突时该规则具有最高优先级。
5. **节奏细节**：指定语速、关键词重音、标点停顿、句尾走势，以及需要避免的错误演法。
6. **纯净输出**：台词前后各保留约 0.5 秒安静；目标句结束后立即静音；不要朗读提示词或表演说明；不添加旁白、第二人声、笑声、喘叫、音乐、音效或环境噪声；输出清晰、干净、近距离的人声。

## 短句强化

短句通常指不超过 8 个汉字的判断、命令、称呼、感叹或极简回答。短句不是低信息任务，必须从前后剧情推断并写出：

1. **触发**：刚看见、刚听见或刚决定了什么。
2. **潜台词**：这句话真正想确认、制止、安抚、试探或保护什么。
3. **起句状态**：呼吸、警觉、迟疑、压低声音或脱口而出中的一种具体状态。
4. **重心与收束**：哪个词承载信息，结尾是咬住、下落、悬着还是收住。

不得用新增文字替代心理表演；成片只能说 JSON 的 `台词`。

## 心理推断边界

优先使用剧本、角色小传、相邻台词和场景内已有事实。可推断合理的即时心理，但不要把未经证实的背景、关系或秘密写成事实。信息不足时，明确使用“谨慎判断”“压住不安”等低断言表述，而不是编造具体经历。

## 固定硬约束段

每条提示词必须原样包含以下内容，只把 `<目标台词>` 替换成该任务的完整台词：

```text
参考音视频只用于复刻音色和自然说话习惯，不得复述、继承或生成参考素材中的原台词、口头禅、旁白、第二人声及背景声音。成片唯一允许出现的人声内容是：“<目标台词>”。必须逐字、完整、只说一次，不得改词、漏词、加词、重复、续说或插入任何其他内容；不得在台词前后添加“好的”“明白”“嗯”“啊”等回应、称呼或语气词，不得朗读提示词和表演说明。目标台词结束后立即静音；若无法准确生成该句，除目标台词外宁可保持静音。
```

该段的内容约束优先于场景、情绪和表演指令。完整目标台词在整个提示词中只能出现一次；后续节奏说明可引用单个关键词，但不要再次粘贴整句。

## 上下文映射

剧本或总览中的信息用于指导表演，而不是照抄进提示词：

- 场景说明 → 声音所处状态与安全/危险感。
- 角色小传 → 年龄感、关系、稳定性格和音色版本。
- 台词括注 → 主次情绪、说话对象、意图、重音与停顿。
- 前后剧情 → 角色知道什么、为何此刻说、哪些情绪必须克制。

不要要求复现参考音视频的原台词、口头禅、旁白、第二人声、背景声或画面内容。参考素材只用于音色和自然说话习惯。

## 提示词流畅性

将提示词写成一条连续的表演逻辑，不要机械罗列形容词。推荐结构：

```text
严格复刻参考音色 → 刚发生什么 → 角色此刻知道与不知道什么 → 对谁说、想达到什么 →
表面与内心的差异 → 这些心理如何落到语速、停顿、重音和句尾 → 严格台词白名单 → 纯净输出
```

- 每个声音指令应有原因，例如“害怕惊动对方，所以压低音量”，而不是孤立写“低声、紧张、克制”。
- 主情绪只保留 1 个，次情绪最多 2 个；冲突情绪必须说明谁在表面、谁在内心。
- 删除不会改变声音表现的剧情介绍，避免提示词冗长后稀释台词和音色约束。
- 不重复粘贴完整目标台词；节奏段只引用必要关键词。
- 不要通过“年轻一点、成熟一点、广东口音、普通话口音、音高更高、共鸣靠前”等词改变声音；需要变化的是表演，不是音色本身。
