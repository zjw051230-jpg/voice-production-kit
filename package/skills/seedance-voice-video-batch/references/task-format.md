# JSON 输入格式与标注

## 文件名

将 UTF-8 JSON 文件直接放在当前项目的 `文字素材` 兼容路径：

```text
task_id+1个任务.json
task_id+12个任务.json
```

`task_id` 是任务标识，`N` 是文件内任务对象数量。文件名必须以 `+N个任务.json` 结尾，且 N 必须等于 JSON 数组长度。不要为每个 JSON 另建输入文件夹。

## 内容

根节点必须是非空数组；即使只有一个任务，也要用 `[ ... ]`。每项必须且只能包含以下六个字段：

```json
[
  {
    "剧本名字": "末日",
    "task_ID": "ABC123_1",
    "角色名字": "阿瓜",
    "台词": "不到十分钟。",
    "时长": "4秒",
    "提示词": "以我上传的参考视频中主要女性说话者的声音作为月儿的唯一音色参考……"
  }
]
```

- `剧本名字`：同一 JSON 内保持一致，并与 `角色音色素材` 下的一级分类目录完全一致，例如 `末日`。
- `task_ID`：必须为 `<文件名中的task_id>_<x>`，x 是对象在数组中的序号，从 1 开始且不补零。
- `角色名字`：与分类目录下的角色文件夹完全一致，用于匹配 `角色音色素材\<剧本名字>\<角色名字>`。
- `台词`：保留原文与标点，并且必须完整出现在提示词中。
- `时长`：正整数秒字符串，例如 `4秒`；没有规定时，由上游写为 `4秒`。
- `提示词`：可直接提交 Seedance 的单段中文提示词。

条目按数组顺序自动标注为 `001`、`002`、`003`……。

## 角色素材

默认通过“剧本分类＋角色名”精确寻找，例如：

```text
<project_root>\角色音色素材\末日\阿瓜\阿瓜加入队伍_最后短视频.mp3
<project_root>\角色音色素材\末日\阿瓜\阿瓜加入队伍_最后短视频.mp4
```

如输入角色名与实际文件夹名不同，可在该剧本分类目录内创建 `角色映射.json`：

```json
{
  "玩家男声": "林警官男声",
  "玩家女声": "林警官女声"
}
```

每个角色目录可用 `reference.json` 写明额外要求，只上传指定素材。支持单个或多个文件：

```json
{
  "videos": ["指定参考1.mp4", "指定参考2.mp4"],
  "audios": ["指定参考1.mp3"]
}
```

也兼容单数键 `video`、`audio`。没有 `reference.json` 时，上传角色目录内全部支持的 MP4/MP3 及其他支持格式，不再只选择最大的文件。每次流水线运行都重新上传这些素材。每个 Seedance 生成请求始终附带一个参考视频和一个参考音频；四个版本按顺序轮换已上传素材。没有独立音频时从参考视频提取 WAV；没有参考视频时停止该角色任务。

## 输出标注

以输入文件名去掉 `.json` 作为视频和 MP3 的同名输出目录。每条台词生成四版：

```text
ABC123_1_阿瓜_不到十分钟。_v01.mp4
ABC123_1_阿瓜_不到十分钟。_v02.mp4
ABC123_1_阿瓜_不到十分钟。_v03.mp4
ABC123_1_阿瓜_不到十分钟。_v04.mp4
```

MP3 与视频同名。提取时使用 JSON `台词`做中文语音强制对齐：只删除目标句之外的其他发言；静音、呼吸、环境留白和句中停顿全部保留，某一侧没有额外发言时该侧不得裁短。识别器无法证明存在其他发言时完整保留原音轨，不按静音或音量裁剪。状态文件同时记录输入 JSON、剧本分类、输入 `task_ID`、条目序号、角色、原台词、时长、版本和远端任务 ID。`.seedance-state.json` 不包含 API Key，不要删除。
