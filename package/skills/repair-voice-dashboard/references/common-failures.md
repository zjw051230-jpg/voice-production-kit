# 常见故障

| 现象 | 自动处理 | 人工边界 |
|---|---|---|
| 工作区换盘或换用户 | 按明确旧/新前缀备份并替换 JSON | 无法推断新位置时询问用户 |
| 注册表缺失 | 从含 `.codex` 的项目重建 | 同名冲突需人工选择 |
| 兼容目录联接失效 | 按映射重建 | 真实目标也丢失时停止 |
| 看板配置损坏 | 备份后重建桌面程序配置 | 无 |
| EXE 缺失 | 有 PyInstaller 时从 skill 源码重建 | 无 PyInstaller 时重新运行安装包 |
| 桌面快捷方式丢失 | 指回工作区隐藏 app 目录中的 EXE | 无 |
| 权限拒绝 | 报告准确路径 | 不自动改 ACL |

路径替换仅限 `项目注册表.json`、项目 `.codex` JSON 和看板配置。任何修复都不得扫描后改写媒体内容。
