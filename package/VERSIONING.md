# 全局版本规则

每次调整都必须新建版本，不在旧版本目录中原地修改。安装包、文档、test 使用完全相同的版本名。

一次发布必须同步完成：

1. 更新 `安装包\<新版本>` 中的技能、脚本、配置样例、安装说明和 `manifest.json`。
2. 更新 `文档\<新版本>` 中给人阅读的精简说明。
3. 用新安装包在 `test\<新版本>` 执行一次隔离安装，保留生成的文件系统和 `TEST-RESULT.md`。
4. 运行全部技能校验、脚本语法检查、Seedance 自测和安装验证。
5. 检查没有真实 API 密钥、生产素材、服务器上传或 `D:\codex-board`。

只修改某一个位置不算完成。旧版本保留用于回退。
