# 配音工作流工具 v2.1 更新公告

发布日期：2026-08-11  
适用平台：Windows  
GitHub：<https://github.com/zjw051230-jpg/voice-production-toolkit4bingchuan>  
更新分支：`develop/v2.1`

## 本次更新

- 强制使用“理解文本与任务、提示词、生成、监控、拉回、记录”六个独立 Codex 任务，入口不再单独完成整套流程。
- 每个任务必须登记真实 thread ID、指定模型、思考程度和完全访问验证结果。
- 主任务派发后停止并等待反馈；目标任务忙碌时每 5 分钟重试，禁止同一任务同时处理两项工作。
- “记录”任务改为单向终止阶段，不再向主任务回报。
- 只有整批满足“成功数 + 失败数 = 总数”后，监控才允许通知拉回；拉回前再次检查终态。
- 配音任务看板增加更清楚的成功、失败、运行中、已下载和终态进度。
- Seedance API 配置工具支持 test版/正式版、多 API 去重、切换和余额不足后的流程暂停。
- CC Switch 只在内置本地代理中精确执行 `gpt-5.5 -> deepseek-v4-pro`，不使用 Codex 模型目录、`model_catalog_json`、无条件 body 覆盖或外置代理。
- 更新快速操作说明、详细用户手册、离线验证和可移植安装包。

## 更新前须知

1. 不要在聊天中发送 API Key。
2. 更新不得删除项目素材、任务 JSON、生成视频、MP3、日志、隐藏任务索引或 CC Switch 用户数据库。
3. 不得向服务器或网络共享目录复制文件。
4. 更新过程中不调用 Seedance 或其他付费生成 API。
5. CC Switch 正在承载当前 Codex 对话时不得主动停止。程序本体如有替换，完成当前工作后由用户手动重启一次。
6. 只允许给当前选中的 Codex provider 增加精确 `gpt-5.5 -> deepseek-v4-pro` 路由，其他模型和 provider 全部保持不变。
