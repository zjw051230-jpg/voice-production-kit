# 配音工具 v2.1 使用说明

这套工具把 Codex 作为统一操作入口。用户只需要提供项目资料并说出要做什么，Codex 负责建立目录、整理任务、生成配音、监控、拉回、转 MP3 和记录返工。

## 1. 新电脑安装

把完整的 `安装包\v2.1` 文件夹交给 Codex，然后发送：

```text
完整读取 START-HERE.md，帮我安装配音工具并创建第一个项目。安装时不要调用付费 API，不要上传任何素材。
```

Codex 会询问工作区位置和项目名。工作区建议放在本机数据盘，不要直接放共享服务器。

安装完成后，桌面有三个入口：

| 程序 | 用途 |
| --- | --- |
| `配音任务看板` | 查看所有项目、台词任务和生成进度 |
| `Seedance API配置工具` | 配置 test版或正式版 API |
| `CC Switch` | 管理 Codex provider 和模型映射 |

## 2. 创建项目

直接对 Codex 说：

```text
我要创建项目，名字叫“项目名”。
```

Codex 会继续确认剧本、角色、台词、音色素材、API 和交付位置，不需要手工创建文件夹。

每个项目只有四个主要目录：

| 目录 | 放什么 |
| --- | --- |
| `01_输入资料` | 角色音色、剧本、配音任务 JSON 和临时素材 |
| `02_生产成品` | Seedance 视频和 MP3 音频 |
| `03_交付与版本` | 待提交内容、工作版本和历史版本 |
| `04_管理与记录` | API、日志、索引、问题和改进记录 |

旧工具目录是兼容映射。不要自行删除、改名或解除映射。

## 3. 配置 Seedance API

1. 双击桌面的 `Seedance API配置工具`，也可运行项目 `04_管理与记录\01_API配置` 中的同名 EXE。
2. 选择项目。
3. 选择 `test版` 或 `正式版`。
4. 在遮罩输入框填写 API Key，点击“添加 API”。每添加一份都会立即写入项目配置。
5. 有多份 API 时继续添加。重复项自动忽略；删除或“设为当前”也会立即写盘。

底部“保存并生成配置”用于手动确认或写入失败后的重试。API Key 只保存在本机项目配置中，不要发送到聊天。

## 4. 准备资料

把已有资料告诉 Codex，或放入项目对应目录：

- 角色音色：`01_输入资料\01_角色音色参考\剧本名\角色名`
- 剧本和剧情：`01_输入资料\02_剧情与剧本`
- 配音任务 JSON：`01_输入资料\03_配音任务`
- 临时音视频：`01_输入资料\04_临时素材`

角色有多版音色时，告诉 Codex 使用哪一版。没有选定音色前，Codex 不应提交该角色的生成任务。

## 5. 日常操作

下面这些话可以直接发送给 Codex：

```text
根据这个剧本生成配音提示词，情感充沛一点。
```

```text
用 sdc 生成这个 task，拿到远端 ID 后停止。
```

```text
查看这个 task 的进度，不要重新提交。
```

```text
监控先等整批任务满足“成功数 + 失败数 = 总数”，再把全部成功版本拉回来并转成 MP3。监控期间不会提前下载局部结果，拉回时还会再次检查。
```

```text
这条需要返工，问题是“台词情绪不够”，重新生成两份并记录原因。
```

Codex 会按六个独立 Chat 处理：理解任务、写提示词、生成、监控、拉回、记录。第一次进入项目时，入口 Chat 必须先创建另外五个 Chat、登记互不重复的 thread ID，并逐个验证完全访问权限；未完成前不得开始生产。用户不需要手工维护这些内部状态，但 Codex 不能用一个 Chat 代做全部阶段。

## 6. 查看和交付成品

- 视频：`02_生产成品\01_生成视频`
- MP3：`02_生产成品\02_MP3音频`
- 待提交资料：`03_交付与版本\01_待提交资料`

看板把任务归为“准备中、生产中、待拉回、需处理、已交付”，并显示精确状态、下一步、来源文件、更新时间，以及成功、失败、运行中和已下载数量。整批终态且所有成功版本的 MP4 和 MP3 实际存在后才显示“成品链接”和“复制到地址”；失败版本无需成品。复制操作只复制，不移动、不覆盖；目标地址不能包含双引号。

未经用户明确批准，Codex 不得把文件复制到共享服务器或 UNC 路径。

## 7. 余额不足

任何阶段发现 Seedance API 余额不足时，系统会暂停整个流程，只通知“理解文本与任务”。有备用 API 时自动切换；恢复后只提交没有远端 ID 的版本，不重复计费。

没有备用 API 时，打开 `Seedance API配置工具` 添加新 API，然后让 Codex恢复原任务。不要使用 `--force-regenerate`。

## 8. CC Switch 一次性设置

先在 CC Switch 中配置并选中 Codex provider，然后完全退出 CC Switch。把下面整段话发送给 Codex：

```text
我已经在 CC Switch 中完成 Codex provider 和 API 配置，并已完全退出 CC Switch。请读取 v2.1 安装包中的“API与CCSwitch配置.md”，只允许把显示名严格等于“5.5”的模型映射到“dpskv4”。先 dry-run，确认其他模型、provider、API Key 和 base_url 都不会变化，再备份数据库并执行，最后运行完整性检查。禁止修改任何其他模型。
```

完成后重新启动 CC Switch 和 Codex，在 Codex 中选择显示名 `5.5`。详细步骤见 [配音工具详细使用手册.md](配音工具详细使用手册.md)。

## 9. 遇到问题

可以直接对 Codex 说：

```text
检查并修复配音任务看板，不要修改媒体文件。
```

```text
检查这个项目缺少哪些角色音色、任务资料或 API 配置。
```

```text
根据这个 MP3 找回原始台词、提示词和生成记录。
```

Codex 会把返工和修复结果写入项目 `04_管理与记录\03_问题与改进`。
