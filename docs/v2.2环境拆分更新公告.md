# v2.2 环境拆分更新公告

v2.2 将 CC Switch、Seedance API 配置工具、`gpt-5.5 -> deepseek-v4-pro` 精确路由、Python/ffmpeg 检测迁移到独立 `env4BC`。配音包只保留七个配音 skills、多项目结构、生产流程和配音任务看板。

## 更新合同

只对照 v2.2 清单补齐或更新工具文件，缺什么改什么。允许修改的范围仅包括配音 skills、安装脚本、看板程序和说明文档。

严禁扫描、整理、迁移、改名、覆盖或删除：项目素材、角色音色、任务 JSON、生成视频、MP3、交付与历史版本、日志、问题记录、隐藏 `.codex` 任务清单、API 私有配置、CC Switch 用户数据库和 provider。

更新前后必须报告实际修改的工具文件，并明确报告上述数据目录未被修改。发现未知文件或版本冲突时保留原文件并停止替换，不能自行“清理”或“整理”。
